# Sristy Verma Portfolio

A personal frontend developer portfolio built with Next.js, React, and Tailwind
CSS.

## What is inside

- A responsive single-page portfolio layout
- Sections for profile, experience, skills, projects, and contact
- SEO metadata for the home page
- Component-based structure for easy updates

## Tech stack

- Next.js
- React
- Tailwind CSS

## Run locally

```bash
npm run dev
```

Then open `http://localhost:3000`.

## Build

```bash
npm run build
```
